# Asset licenses and provenance

This file records the intended status of project-shipped visual assets.

| Asset group | Status | Notice |
| --- | --- | --- |
| `assets/branding/*` | Project artwork incorporating Material Icons | The cleaning-services glyph is from Material Icons and is Apache 2.0 licensed; see the attribution comment in `app_icon.svg`. |
| `fastlane/screenshots/*` | Project-generated screenshots | Generated by `integration_test/screenshot_test.dart` using the built-in demo home, synthetic vacuum data, and an embedded synthetic map. No Home Assistant installation or personal household data is used. |
| `fastlane/metadata/android/en-US/images/*` | Project-generated screenshots | Same demo-only source as the desktop screenshots. |
| Flutter/platform-generated icons | Project build outputs | Generated from the project branding assets during platform builds. |

Before adding a new asset, record its source, license, and any required
attribution here. Do not commit screenshots containing real Home Assistant
URLs, access tokens, maps, device names, or household information.
